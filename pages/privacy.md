Last updated: 8 November 2026

This website is the personal site of Aslan Mammadli. It does not sell, share or rent any personal data.

## Public pages

The public pages of this site do not use accounts, forms, advertising or tracking cookies. The web server may keep standard technical logs (such as IP address, browser and time of request) for security and for fixing problems. These logs are kept only for a short time.

## Google sign in and Search Console data

The site has a private dashboard used only by the site owner. It uses Google sign in to read Google Search Console data with read-only access (the `webmasters.readonly` scope) and the account's email address to label which account the data comes from.

- Search Console data is shown only to the signed-in owner and is used only to build performance reports for the owner's own websites.
- The data is not sold, shared with third parties, or used for advertising.
- Access tokens in the browser are kept only in that browser and can be removed at any time with "Sign out all".
- A daily report job stores a summary of clicks, impressions, CTR and average position per site, used only by the owner.
- Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

The use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
